A tiny Node program that writes one haiku in the 5-7-5 shape about debugging — a breakpoint holding its breath, a log line that points at no one, and the typo that was mine all along. Before writing, the program counts every line's syllables and refuses to write anything that is not exactly 5-7-5 within the 200-character gate.

## Run it

```sh
node main.ts
```

This writes the haiku to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set), with no trailing newline.
